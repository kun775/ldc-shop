# Design System: Linear × Stripe for ldc-shop

> 针对数字资产 / 发卡网 / 虚拟服务商城的高精工设计语言规范（融合 Linear 极客精工交互与 Stripe 极简信任交易系统）。

---

## 1. Visual Theme & Atmosphere (视觉基调与设计哲学)

- **核心定位**：高信任、高密度、零视觉噪点的现代化数字电商平台。
- **双模态融合设计**：
  - **前台（Storefront & Checkout）**：继承 **Stripe** 的高转换率与支付信任美学。纯净卡片表面、柔和微层次阴影、严格对齐的数据与价格字阶（`tabular-nums`）、明确的履约时效担保与退款保障标识。
  - **后台（Admin Dashboard & Editor）**：继承 **Linear** 的工程级操控手感与信息密度。暗色/浅色自适应表面梯级、微半透明分割线（`rgba(255,255,255,0.08)` / `rgba(0,0,0,0.08)`）、粘性顶部操作栏（Sticky Action Header）、高密度字段与快捷键响应（`⌘S` 保存、`⌘K` 指令搜索）。
- **字体规范**：
  - 西文与通用：`Inter Variable`（启用 OpenType 特性 `"cv01"`, `"ss03"` 呈现几何美感，数字启用 `"tnum"` 对齐金额）。
  - 等宽代码：`JetBrains Mono` / `Berkeley Mono` / `SF Mono`（用于卡密输出、订单ID、API Key、加密哈希展示）。
  - 中文：系统无衬线优先（`PingFang SC`, `Microsoft YaHei`, `Noto Sans SC`）。

## 2. Color Palette & Roles (色彩与语义角色)

### 2.1 Brand & Interactive Accents
- **Linear Indigo (品牌交互主色)**: `#5e6ad2`（按钮主色、核心 CTA、高亮选中）
- **Accent Violet (悬浮交互色)**: `#7170ff`（Hover 状态、激活指示条）
- **Subtle Violet (浅色背景底色)**: `#eeedfe`（Dark: `rgba(94,106,210,0.15)`，用于选中状态、标签高亮）

### 2.2 Semantic & Fulfillment Accents
- **⚡ 自动发卡 (Instant Auto-Delivery)**:
  - 强调色：`#5e6ad2` (Indigo)
  - 徽章底色：`#eeedfe` (Light) / `rgba(94,106,210,0.2)` (Dark)
  - 语义：库存充足、付款后毫秒级自动吐卡、零等待
- **📦 手工履约 (Manual Fulfillment)**:
  - 强调色：`#185fa5` (Stripe Blue)
  - 徽章底色：`#e6f1fb` (Light) / `rgba(24,95,165,0.2)` (Dark)
  - 语义：定制服务/附件下载、支持大文件分发、售后跟踪
- **Success (已支付/已交付)**: `#0f6e56` / 浅底 `#e1f5ee` (Emerald)
- **Warning/Pending (待发货/待支付)**: `#ba7517` / 浅底 `#faeeda` (Amber)
- **Danger (退款/库存耗尽)**: `#e24b4a` / 浅底 `#fcebeb` (Coral Red)

### 2.3 Surfaces & Elevation (表面与层级)
- **Layer 0 (底画布)**: Light `#f7f8f8` | Dark `#08090a`
- **Layer 1 (面板/侧边栏)**: Light `#f3f4f5` | Dark `#0f1011`
- **Layer 2 (卡片/弹窗/浮层)**: Light `#ffffff` | Dark `#191a1b`
- **Layer 3 (悬浮/高亮控件)**: Light `#f0f1f3` | Dark `#23252a`
- **Border**: `0.5px solid rgba(0,0,0,0.08)` (Light) / `0.5px solid rgba(255,255,255,0.08)` (Dark)

## 3. 6 大核心模块 UI/UX 详细交互规范与重构方案

### 3.1 商品编辑页面 (Admin Product Form)
- **痛点解决**：
  1. **粘性顶部操作条 (Sticky Action Header)**：无论页面滚到哪里，商品标题、在售状态、快捷键 `⌘S` 提示以及「保存变更」按钮始终在视口顶端，避免找不到保存按钮。
  2. **逻辑分区折叠 (Segmented Sections)**：
     - **区块 1：基础信息与发货模式**（商品名、Slug、发货模式 Auto vs Manual 单选卡片卡位）。
     - **区块 2：定价与积分策略**（单价、划线原价、限购件数、积分最高可抵扣百分比与开关）。
     - **区块 3：下单信息采集字段 (Checkout Fields)**（可视化项列表、拖拽手柄、字段类型徽章、必填/选填快速切换、即时添加抽屉）。
     - **区块 4：购买前说明与安全问答 (Notice & Q&A)**（弹窗风险提示、强制问答配置）。
     - **区块 5：多媒体图库 (Media & Gallery)**（主图、多图拖拽排序、批量上传状态指示）。
  3. **实时双栏前台预览 (Live Storefront Preview)**：
     - 右侧设立实时预览卡片，编辑字段时前台卡片和详情页买框 1:1 动态响应，所见即所得。

### 3.2 商品浏览页面 (Storefront Catalog)
- **痛点解决**：
  1. **高敏捷搜索与过滤中枢**：
     - 搜索栏支持快捷键 `/` 直接聚焦，实时防抖。
     - 状态过滤胶囊：[全部] [⚡ 自动秒发] [📦 手工交付] [仅看有货] [积分可抵扣]。
  2. **商品卡片重构**：
     - 固定等比图片容器（4:3 或 16:9），带有半透明发光图标与圆角剪裁。
     - 价格与库存看板：主价大字号粗体突出，划线原价与折扣率紧随其后；库存数精确显示，手动发货商品显示「平均交付时效」。
     - 悬浮动效：微幅上浮（`translateY(-2px)`）+ 边框颜色平滑过渡为 Accent 品牌色。

### 3.3 商品详情页 (Storefront Product Detail)
- **痛点解决**：
  1. **规格变体 (Variants) 芯片选择器**：
     - 从下拉框或纯文字升级为**大尺寸交互卡片芯片**，卡片内同时显示变体名、变体差价、实时库存状态，一击切换。
  2. **履约保障信用看板 (Fulfillment Trust Banner)**：
     - 在购买卡片下方直观呈现履约链路：自动发卡显示「⚡ 付款后立即出密 + 邮件同步存底」；手工商品显示「📦 附带操作教程与安装包下载」。
  3. **自适应布局平衡**：
     - 采用左侧媒体/长富文本与右侧 Sticky 购买盒的黄金比例，长表单场景右侧面板自动滚动收纳。

### 3.4 下单流程 (Checkout Flow)
- **痛点解决**：
  1. **消除上下文割裂 (Unified 1-Step Stepped Checkout)**：
     - 将原本“页面填表单 + 弹窗填邮箱/选积分”的双重流程整合。所有字段（自定义采集信息、接收邮箱、积分抵扣）在右侧购买面板或一站式 Modal 中无缝贯通。
  2. **积分动态抵扣计算器**：
     - 直观显示「我的积分余额」、「本次最高可抵扣金额」，勾选后价格明细即刻产生带有删除线与减免绿色的平滑动画。
  3. **行内精确校验 (Inline Validation)**：
     - 必填项若未填，输入框直接高亮边框并显示红色辅助提示，自动将焦点移动至第一项缺失字段。

### 3.5 订单详情页 (Order Detail - User & Admin)
- **痛点解决**：
  1. **前台用户端 (User Order Hub)**：
     - **4 阶履约状态步进器**（提交订单 → 支付确认 → 正在履约 → 交付完成），每一步均标注精确到秒的完成时间。
     - **卡密输出控制台**：采用等宽代码块黑底展示，支持「逐行复制」、「一键复制完整凭据」、「隐藏/显示敏感信息」。
     - **富附件交付卡片**：交付文件以专属格式卡片呈现（PDF / ZIP / 源码），标明文件体积、上传时间，带独立一键下载按钮。
  2. **后台管理员端 (Admin Order Detail)**：
     - **手工发货工作台**：待发货订单顶部突出待办条，内置富文本发货说明快捷模板、拖拽式附件上传区（显示当前 R2 / D1 存储用量与限额）。

### 3.6 后台管理页面整体 (Admin Dashboard)
- **痛点解决**：
  1. **全局指令中枢 (Command Palette - `⌘K`)**：
     - 支持全局搜索订单号、商品名称、快捷切换至设置页。
  2. **高密度实时指标色带 (Metrics Ribbon)**：
     - 4 张轻量看板卡片：今日营收、待手动发货笔数、在售商品充足率、待处理售后退款。
  3. **表格交互升级**：
     - 订单表格高亮显示待发货行，操作列提供「一键发货」快捷弹窗，无需跳转新页面即可录入交付内容。
